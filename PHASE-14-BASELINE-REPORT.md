- Phase 13 factory is deterministic and uses only reviewed processors from `lib/tool-engine/registry.ts`.
- The factory endpoint is admin-protected and creates `REVIEW` / non-indexable candidates transactionally.
- The current factory route performs processor regression checks synchronously in the request path.
- `.env.example` already lists provider key/model variables for OpenAI, Anthropic, Gemini, Groq, OpenRouter, Mistral, and Cloudflare.
- No package lockfile was included in the archive.

## 3. Initial Phase 14.1 scaffold added

- `lib/ai/types.ts`: provider-neutral task, provider, request, response, usage, error, and adapter contracts.
- `lib/ai/router.ts`: deterministic provider selection based on explicit task capability, enabled state, configured key/model, priority, and excluded providers.
- `lib/ai/config.ts`: server-side environment-based provider discovery. It reads secrets from environment variables and does not persist them.
- `tests/ai-router.test.ts`: unit tests for task capability filtering, priority ordering, fallback exclusion, and missing credentials.

The scaffold does not yet send network requests to AI providers. Provider adapters, timeout/retry policy, token/cost accounting, admin endpoints, and DB integration are subsequent Phase 14.1 tasks.
