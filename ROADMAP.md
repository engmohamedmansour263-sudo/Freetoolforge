## Phase 14.7 — Factory Operations Dashboard

Deliver an admin interface for durable factory jobs: queue visibility, status filtering, manual worker invocation, cancellation, and retry. This is an operational dashboard, not a worker supervisor; production parallel workers must run as separately supervised processes.
